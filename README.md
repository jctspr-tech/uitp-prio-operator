# Бесплатная AI копия помощника оператора

Отдельная версия проекта УИТП с реальной открытой моделью Qwen2.5-0.5B-Instruct, выполняемой в браузере через WebLLM 0.2.85. Бесплатная AI-копия: https://uitp-prio-ai.onrender.com/. Исходный сайт https://uitp-prio-operator.onrender.com/ и ветка main не изменяются. Эта копия размещается на Render из отдельной ветки ai-live.

Запросы не требуют OpenAI API, ключа или покупки кредитов. Модель обрабатывает вопрос локально. При первой инициализации загружаются веса модели, токенизатор и WebAssembly библиотека с того же адреса сайта. Веса и конфигурация занимают около 290 МБ, дополнительный runtime увеличивает загрузку; требуется около 1 ГБ видеопамяти и WebGPU. Для демонстрации используйте современный Chrome или Edge и искусственные обезличенные вопросы. Кэш браузера может ускорять следующие посещения; удаление данных сайта очищает кэш.

Черновик генерирует настоящая модель по отобранным публичным материалам. Источники остаются пересказами исследовательского снимка, а не утверждёнными регламентами. Проверки структуры и ссылок не доказывают правильность каждого факта. Оператор обязан сверять ответ; качество ≥90% не измерено. Учебные контрольные сценарии помечены как локальные проверки правил, их ответы не выдаются за модельную генерацию.

Первые загрузка и генерация могут занять время. При отсутствии WebGPU, ошибке загрузки, отмене или неверном ответе модели интерфейс показывает ограничение; заранее подготовленный текст не подменяет живой AI-результат. Ручная база материалов остаётся доступной.

Для подготовки статических файлов:

    node build.mjs

Для локального показа:

    python3 -m http.server 8143 --bind 127.0.0.1 --directory dist

Откройте http://127.0.0.1:8143/. WebGPU требует безопасного контекста, HTTPS либо localhost. На Render используется HTTPS. Платный API-сервер не нужен и не публикуется. Build загружает фиксированную версию WebLLM и неизменный снимок файлов модели из исходных публичных репозиториев, проверяет размеры и SHA256 и размещает их в dist. Браузер скачивает веса с сайта при первом запуске; тексты обращения внешнему AI-сервису не передаются. Такая модель расходует обычный трафик статического сайта в пределах квот Render; платные опции не подключаются.

Официальные источники: https://webllm.mlc.ai/docs/user/basic_usage.html и https://github.com/mlc-ai/web-llm . Модель: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct .
